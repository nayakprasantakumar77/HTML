Heart Disease Prediction System

Heart Disease Prediction System is a machine learning project developed using Python, Flask, and Scikit-learn to predict whether a patient is likely to have heart disease based on health-related parameters such as age, blood pressure, cholesterol, chest pain, and heart rate.

I performed data preprocessing, feature scaling, and dataset preparation before training the models. Three machine learning algorithms, K-Nearest Neighbors (KNN), Random Forest, and Logistic Regression, were implemented and evaluated based on their performance.

The trained models were integrated into a Flask-based web application where users can enter patient details and receive a prediction. This project helped me gain practical experience in machine learning, data analysis, model evaluation, and web application development.
